# Analytics Pro — демонстрационная CRM

Независимый портфолио-проект на русском: фарм-отдел, медиабаинг, финансы и AI-аналитика.
Все аккаунты, имена и показатели вымышлены. AI-выводы подготовлены заранее, внешних
интеграций, платежей, авторизации и настоящей базы нет.

## Запуск

Node.js 20+; внешние npm-зависимости не нужны.

```sh
npm test
npm run build
npm run dev
```

Открыть http://127.0.0.1:14000. Статическая сборка находится в `dist/`.
Шрифт Golos Text загружается из Google Fonts; без сети используется Arial.

## Концепции

Переключатель в верхней панели: Light, Dark, Studio. Сохраняется только выбор
дизайна в localStorage. Работают навигация, период, поиск, фильтрация, карточки
аккаунтов и экспорт вымышленных данных. График иллюстративный, не временной ряд
реальных операций. Недельные показатели моделируются как 25% месячных.

Ветки `design/light`, `design/dark`, `design/editorial` предназначены для
независимого развития концепций. Старый Analytics Pro не используется и не
обновляется этим проектом. CI проверяет данные и сборку; серверный деплой пока
не настроен.
